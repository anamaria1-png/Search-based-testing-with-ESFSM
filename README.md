Search-Based Testing (SBT) using Extended Finite State Machines (EFSMs) is an automated software testing technique that:

    Models the system behavior as an EFSM, which includes:

        States and transitions

        State variables

        Guards (conditions) and actions

    Transforms test case generation into an optimization problem, where:

        A search algorithm (e.g., genetic algorithms, hill climbing) explores possible paths in the EFSM

        The goal is to maximize coverage (e.g., state, transition, or condition coverage)
